Automatic Project Task Date Tracking

Sync Task Dates with Purchase, Manufacturing & Delivery Orders

Eliminate manual task date updates! This module automatically synchronizes project task planned dates with related Purchase Orders, Manufacturing Orders, and Delivery Orders.

Key Features

📦 Purchasing Tasks

Automatically update task dates based on Purchase Order dates. Start date = earliest PO, End date = latest PO.

🏭 Production Tasks

Sync task dates with Manufacturing Order creation dates. Real-time updates when MOs are planned.

🚚 Delivery Tasks

Track delivery timelines automatically from Delivery Order scheduled dates.

⚡ Real-Time Updates

Dates update instantly when orders are created, confirmed, or modified. No manual intervention needed.

How It Works

Simple 3-Step Process:

  1. Enable Automation: Check the automation flag on your task (Purchasing/Production/Delivery)
  2. Link Orders: Set the project's analytic account on your PO/MO/DO
  3. Automatic Updates: Task dates update automatically when orders are confirmed

Benefits

  • ✅ Save Time: Eliminate manual date tracking and updates
  • ✅ Improve Accuracy: Task dates always reflect actual order status
  • ✅ Better Visibility: Clear timeline view of project phases
  • ✅ Standardized Workflow: Consistent task tracking across all projects
  • ✅ Real-Time Sync: Instant updates when orders change

Technical Details

Date Sources:

  • Purchasing Tasks: PO date_order (Order Date)
  • Production Tasks: MO date_start (Start Date)
  • Delivery Tasks: DO scheduled_date (Scheduled Date)

Linking Method:

All orders are linked to projects via the Analytic Account. The module automatically finds related orders and calculates date ranges.

Update Triggers:

  • Purchase Orders: Create, Confirm, Modify
  • Manufacturing Orders: Create, Plan, Modify
  • Delivery Orders: Create, Validate, Modify
